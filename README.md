# Accessible City Assistant (ASP.NET Project)

## Project Overview
Mobility for people with disabilities is one of the most important challenges in modern society. This project aims to provide a convenient and accessible system that supports mobility and assistance within the city.  

The application allows users with disabilities to create help requests, while other users (assistants) can respond to these requests in real-time. It also includes route planning considering urban accessibility and an emergency help request feature.  

---

## System Architecture
The system consists of:
- **Database** – used for storing and managing all system data.  
- **Application Layer** – provides secure interaction with the database, minimizing risks of unauthorized interference.  

The project is built using:
- **Language & Framework**: C# with **ASP.NET Web Framework**  
- **Database**: Microsoft SQL Server  
- **Data Access**: ADO.NET  

---

## Features
- 🆘 **Emergency Help** – send immediate emergency requests.  
- 🙋 **Help Requests** – users can create requests for assistance.  
- 🤝 **Assistance Response** – other users can respond to help requests and close them once resolved.  
- 🔧 **Administration** – administrators ensure the accuracy and relevance of accessibility data.  

---

## User Roles
| Role              | Description |
|-------------------|-------------|
| **Administrator** | Maintains up-to-date data about city accessibility and manages user requests. |
| **User**          | Creates help requests, builds accessible routes, and can send emergency calls. |
| **Assistant**     | Responds to help requests, provides assistance, and handles emergency alerts. |

---

## User Scenario
1. The user logs into the system.  
2. Chooses the option **“Create Help Request”** or navigates to the respective menu section.  
3. Fills in the necessary details and submits the request.  
4. Another user (assistant) sees the request, responds to it, and closes it after completion.
